Old university coursework and team projects (University of Houston–Downtown), consolidated into one attic.

- `UHD_CS3321-Spr2020-25973-LMS` — software engineering team project: a "4K Learn" learning management system (from ajpri/UHD_CS3321-Spr2020-25973-LMS)
- `MARIA` — open-source implementation of the MARIE architecture simulator, in C++ (from ajpri/MARIA)
- `COSC2336-302` — data structures coursework (from ajpri/COSC2336-302)
- `3318DB-Project` — database course project (from ajpri/3318DB-Project)
- `nxGraphAlgorithms` — discrete math group project: graph algorithms in Python (from ajpri/nxGraphAlgorithms)

Each folder was imported from its standalone repository at its latest commit; folder-level provenance is in the git history.
- `thinginternetprotocol` — Thing Internet Protocol (TIP): an open-source smart home protocol, spec v0.05, with a Wyze sample integration, C++ toolkit, and weather station example (from ajpri/thinginternetprotocol)
